### ✅ 1. 오늘 배운 내용

**① JavaScript 조건문 활용**
- `if`, `else if`, `else`를 활용한 조건 분기
- 비교 연산자로 회원 상태 판단

**② 배열(Array) 이해**
- 배열을 이용해 여러 데이터를 하나의 변수에 저장

**③ 반복문 활용**

- `index + 1`을 활용하여 번호와 함께 목록 출력

**④ VS Code와 Console의 차이**
- VS Code: JavaScript 코드 작성 및 수정
- Console: 코드 실행 결과 확인 및 테스트
- `app.js` 수정 → 저장 → 실행 → Console 확인 과정 학습

### 💻 2. 주요 실습 코드

```javascript
const members = ["민수", "지연", "현우"];

members.push("서연");

members.forEach((name, index) => {
  console.log(`${index + 1}. ${name}`);
});
```

**실행 결과**
```text
1. 민수
2. 지연
3. 현우
4. 서연
```
