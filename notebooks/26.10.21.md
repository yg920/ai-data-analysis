### 1. JavaScript 기초 실습

**① HTML 입력창과 CSS 스타일링**
- 기존 이름 입력창 왼쪽에 나이 입력창 추가
- CSS를 활용한 입력창 크기, 간격 및 배치 조정
- 사용자 입력을 받을 수 있는 화면 구성

**② DOM 조작 및 실시간 화면 변경**
- `document.getElementById()`로 HTML 요소 선택
- `input.value`를 이용해 입력값 가져오기
- `textContent`를 활용해 화면의 문구 변경
- 초기에는 '안녕하세요 환영합니다'를 표시하고, 이름 입력 시 '안녕하세요 XXX님 환영합니다'로 변경

**③ 배열을 활용한 회원 관리**
- 이름과 나이를 입력받아 회원 목록 배열에 추가
- `push()`를 이용해 신규 회원 데이터 저장
- 마지막 회원의 ID에 1을 더해 새로운 ID 생성
- 나이가 50세 이상이면 `isActive: false`, 미만이면 `true` 설정
- 추가된 회원을 화면의 회원 목록에 출력

### 2. PostgreSQL Chapter 14 실습

**① 분석용 데이터셋 이해**
- Python 데이터 분석에 활용할 PostgreSQL VIEW 구성
- 수강신청 1건을 하나의 행으로 정리하는 분석 구조 학습
- 원본 테이블을 수정하지 않고 VIEW를 통해 분석 데이터 제공

**② SQL 실행 환경 점검**
- `current_database()`로 현재 데이터베이스 확인

- `SHOW search_path`로 스키마 탐색 경로 확인
- `to_regclass()`를 활용한 테이블 존재 여부 점검
- SQL 실행 중 발생하는 오류와 실행 조건 확인

## ⚠️ 어려웠던 점 및 해결 과정

**1. JavaScript 입력값과 배열 데이터 연결**

입력창에 작성한 이름과 나이를 JavaScript 객체로 만들고 배열에 추가한 뒤 화면에 출력하는 흐름을 이해하는 데 집중했다. ID 자동 증가와 나이에 따른 회원 활성화 조건을 구현하면서 배열과 조건문의 활용 방법을 익혔다.

**2. SQL 실행 오류**

Chapter 14 분석용 SQL을 실행하면서 여러 오류가 발생해 데이터베이스, 스키마, 테이블 구조 및 쿼리 실행 조건을 점검했다. SQL 작성뿐 아니라 실행 환경을 정확하게 확인하는 과정도 중요하다는 점을 알게 되었다.

**3. Python 파일 경로 오류**

`requirements.txt` 파일을 찾지 못하는 문제가 발생했다. 상대경로가 현재 터미널 위치를 기준으로 해석된다는 점을 확인했고, 패키지 설치 전에 실제 폴더 구조와 작업 위치를 확인해야 한다는 점을 배웠다.
