## 1. 쇼핑몰 메인화면 UI 개선

### 작업 내용
- 기존 상품 데이터 나열형 화면을 실제 쇼핑몰 형태로 개선
- 공통 컴포넌트 `ProductCard.tsx` 적용
- 상품 이미지, 가격, 할인율, 평점, 배송 정보 중심으로 카드 구성
- 불필요한 상세 정보는 상품 상세페이지로 분리
- 반응형 상품 카드 그리드 적용

### 배운 점
- 컴포넌트를 분리하면 재사용성과 유지보수성이 높아진다.
- 상품 목록에서는 구매 결정에 필요한 핵심 정보만 보여주는 것이 효과적이다.
- Tailwind CSS의 `grid`, `gap`, `rounded`, `hover` 등을 활용해 쇼핑몰 UI를 구성할 수 있다.

## 2. 자동 슬라이드 메인 배너 구현

### 작업 내용
- `components/MainBanner.tsx` 생성
- React의 `useState`, `useEffect` 활용
- `setInterval()`을 이용한 5초 자동 슬라이드 구현
- 이전/다음 버튼 및 하단 페이지 인디케이터 추가
- 마지막 배너 이후 첫 번째 배너로 무한 반복
- 페이드 전환 효과 적용

### 핵심 코드

`useEffect()`에서 타이머를 등록하고, 컴포넌트 정리 시 타이머를 제거한다.

`setCurrentIndex((prev) => (prev + 1) % banners.length);`

### 배운 점
- `useState`: 현재 배너 번호 관리
- `useEffect`: 자동 슬라이드 타이머 관리
- `setInterval`: 일정 시간마다 반복 실행
- `clearInterval`: 불필요한 타이머 정리
- `% banners.length`: 마지막 배너 이후 첫 번째 배너로 이동

## 3. 반응형 배너 및 이미지 처리

### 작업 내용
- PC, 태블릿, 모바일에 맞게 배너 높이 조정
- `object-cover`를 활용한 이미지 자동 크롭
- `overflow-hidden`을 활용한 배너 영역 관리
- 메인화면 구성 순서 변경

### 최종 화면 구성
1. Header
2. 자동 슬라이드 배너
3. 국가별 카테고리 메뉴
4. 상품 카드 목록
5. Footer

### 배운 점
- `object-cover`: 이미지 비율을 유지하면서 영역 채우기
- `object-center`: 이미지 중앙 기준 크롭
- `sm:`, `lg:`: 화면 크기에 따른 반응형 스타일 적용
- 컴포넌트 배치 순서만 변경해도 메인화면 구조를 개선할 수 있다.

## 4. AI 활용 팀원별 캐릭터 배너 제작

### 작업 내용
- 기존 국가별 간식 배너 이미지 제작
- 팀원별 특징을 반영한 캐릭터 이미지 생성
- 각 팀원의 추천 과자를 테마로 PICK 배너 제작
- 캐릭터별 의상, 헤어스타일, 성격, 색상, 포즈 반영
- 기존 배너를 팀원별 추천 배너로 변경

### 제작한 배너
- 희주 PICK: 곤약젤리, 포키
- 예주 PICK: 초콜릿
- 종복 PICK: 감자과자
- 강 PICK: 초콜릿
- 지나 PICK: 김과자, 바나나칩
- 추가 희주 PICK: 다시마젤리

### 배운 점
- AI 이미지 생성 시 인물의 특징을 구체적으로 설명하는 것이 중요하다.
- 동일한 스타일을 유지하면 쇼핑몰의 디자인 일관성을 높일 수 있다.
- 생성된 이미지를 `public/images/common/`에 저장하고 코드에서 경로를 지정하여 사용할 수 있다.

## 5. GitHub Merge 및 협업

### 작업 내용
- 팀원들이 작업한 최신 코드를 Merge하여 반영
- Merge 이후 기존 배너 컴포넌트 재연결
- 팀원이 제작한 `ProductCard.tsx` 기능 유지
- 상품 데이터와 메인화면 컴포넌트 충돌 최소화
- 팀원들의 최신 코드 적용 과정에서 배너 작동 문제 점검

### 주요 명령어
- `git status`: 변경된 파일 확인
- `git branch --show-current`: 현재 브랜치 확인
- `git pull`: 원격 저장소 변경사항 가져오기
- `git add`: 변경 파일 스테이징
- `git commit`: 변경사항 기록
- `git push`: 원격 저장소에 반영

### 배운 점
- Merge 이후에는 기존 기능이 정상적으로 작동하는지 다시 확인해야 한다.
- 다른 팀원의 컴포넌트와 Props 구조를 함부로 변경하지 않는 것이 중요하다.
- Git에서 `U`로 표시되는 추적되지 않은 파일은 커밋에 포함했는지 확인해야 한다.

## 6. 자동 배너 오류 원인 분석

### 발견한 문제
GitHub 최신 코드를 받은 일부 팀원의 환경에서 배너가 자동으로 넘어가지 않는 문제 발생

### 점검한 내용
- `onMouseEnter`로 인해 마우스가 배너 위에 있을 때 슬라이드가 멈추는 동작 확인
- `useEffect` 타이머 실행 조건 검토
- 배너 이미지 파일의 GitHub 업로드 여부 점검 안내
- 팀원별 브랜치 및 최신 코드 반영 여부 확인 방법 정리

### 개선 방향
- 필요 시 마우스 호버 일시 정지 기능 제거
- 자동 전환 타이머를 단순화
- 팀원별 실행 환경에서 재검증

※ 오류의 최종 원인은 아직 확정되지 않았으며 추가 확인이 필요하다.
