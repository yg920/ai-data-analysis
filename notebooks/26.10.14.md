## 4. 학습 내용

### 4.1 requests를 이용한 웹페이지 요청

Python의 requests 라이브러리를 이용해 YES24 도서 상세 페이지에 접근했다.

```python
import requests

book_id = "139807878"

url = f"https://www.yes24.com/Product/Goods/{book_id}"

response = requests.get(
    url,
    headers={"User-Agent": "Mozilla/5.0"},
    timeout=15
)

print(response.status_code)
```

**실행 결과**

```text
200
```

HTTP 상태 코드 200은 요청이 정상적으로 처리되었다는 의미다.

### 4.2 BeautifulSoup으로 HTML 분석

웹페이지에서 가져온 HTML을 분석하기 위해 BeautifulSoup을 사용했다.

```python
from bs4 import BeautifulSoup

soup = BeautifulSoup(
    response.text,
    "html.parser"
)

text = soup.get_text(" ", strip=True)
```

학습한 내용:
- `response.text`: 웹페이지 HTML 가져오기
- `BeautifulSoup`: HTML 구조 분석
- `select_one()`: CSS 선택자로 특정 요소 찾기
- `get_text()`: HTML 태그를 제거하고 텍스트 추출

### 4.3 JSON-LD에서 ISBN 추출

HTML에 포함된 구조화 데이터(JSON-LD)를 이용해 ISBN을 추출했다.

**테스트 결과**

```text
상품번호: 139807878
ISBN: 9791172131784
HTTP 상태: 200
```

JSON-LD는 검색엔진 등이 웹페이지의 상품 정보를 이해할 수 있도록 제공되는 구조화 데이터다.

이를 통해 HTML 화면에 표시된 텍스트 외에도 도서 식별 정보를 추출할 수 있다는 것을 학습했다.

### 4.4 정규표현식으로 필요한 정보 추출

리뷰 평점과 리뷰 건수를 가져오는 과정에서 정규표현식 오류가 발생했다.

**실제 HTML 텍스트**

```text
평균 별점 9.6 ( 9 )
판매지수 132,366
```

**기존 문제**

정규표현식이 `(9)` 형식만 처리하도록 작성되어 `( 9 )`처럼 공백이 포함된 데이터를 인식하지 못했다.

**수정 코드**

```python
import re

rating_match = re.search(
    r"평균\s*별점\s*(\d+(?:\.\d+)?)\s*\(\s*([\d,]+)\s*\)",
    text
)

sales_match = re.search(
    r"판매지수\s*([\d,]+)",
    text
)
```

**학습한 내용**

- `\s*`: 공백이 0개 이상 존재하는 경우 허용
- `\d+`: 숫자 추출
- `group()`: 정규표현식에서 일치한 값 가져오기
- `replace(",", "")`: 숫자의 쉼표 제거
- `int()`: 정수로 변환
- `float()`: 실수로 변환

문자열의 공백과 형식 차이 때문에 데이터 추출에 실패할 수 있다는 것을 이해했다.

### 4.5 Excel 데이터를 DataFrame으로 변환

Pandas를 사용해 원본 Excel 파일을 DataFrame으로 불러왔다.


**실행 결과**

```text

상품번호 누락: 0
상품번호 중복: 0
```

학습한 내용:
- `read_excel()`: Excel 파일 불러오기
- `dtype`: 데이터 타입 지정
- `shape`: 행과 열 개수 확인

### 4.6 반복문으로 여러 도서 크롤링

또한 분석 결과를 리스트에 저장한 뒤 DataFrame으로 변환하는 방법을 익혔다.

### 4.7 tqdm으로 진행률 표시

전체 도서 크롤링 시 책마다 로그를 출력하면 결과를 확인하기 어려웠다.

따라서 tqdm을 이용해 진행률만 표시하도록 코드를 변경했다.

```python
from tqdm.auto import tqdm

for _, row in tqdm(
    df_books.iterrows(),
    total=len(df_books),
    desc="YES24 크롤링",
    unit="권"
):
    pass
```

이 방법으로 작업 진행 상황을 퍼센트(%)와 처리 건수로 확인할 수 있다.

### 4.9 Pandas Merge 학습

기존 도서 데이터와 크롤링 결과를 상품번호 기준으로 병합하는 방법을 학습했다.

```python
df_total = pd.merge(
    df_raw,
    df_ext,
    on="상품번호",
    how="left",
    validate="one_to_one",
    indicator=True
)
```

**주요 옵션**

| 옵션 | 의미 |
|---|---|
| `on` | 병합 기준 컬럼 |
| `how="left"` | 왼쪽 원본 데이터 유지 |
| `validate="one_to_one"` | 양쪽 데이터의 키 중복 검증 |
| `indicator=True` | 병합 성공 여부 확인 |

이번 실습에서는 원본 206권을 유지하는 것이 중요하므로 LEFT JOIN 방식을 선택했다.

### 4.10 상대 경로 오류 해결

데이터 병합 과정에서 `FileNotFoundError`가 발생했다.

**오류 원인**

Jupyter Notebook의 실행 위치와 데이터 폴더의 상대 경로가 일치하지 않았다.

잘못된 경로:

```python
Path("../data/raw/books_raw.xlsx")
```

수정한 경로:

```python
Path("../../data/raw/books_raw.xlsx")
```

파일 경로를 수정한 뒤 다음 코드로 존재 여부를 확인하도록 했다.

```python
print(raw_path.exists())
print(ext_path.exists())
```

**배운 점**

상대 경로는 실행 중인 Jupyter 작업 디렉터리를 기준으로 계산되므로, 파일이 존재하더라도 경로 설정이 잘못되면 읽을 수 없다.
