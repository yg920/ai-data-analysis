# 1. 오늘 배운 내용

오늘은 Titanic 데이터셋을 활용하여 데이터프레임의 각 컬럼이 어떤 의미를 가지는지 확인하고, 데이터 분석을 위해 문자열 데이터를 숫자로 변환하는 전처리 과정을 학습했다.

특히 `Sex` 컬럼의 `male`, `female` 값을 머신러닝이나 데이터 분석에서 사용하기 쉽도록 `0`, `1` 형태로 인코딩하는 방법을 실습했다.

# 4. Sex 컬럼

기존 `Sex` 컬럼은 문자열 형태로 구성되어 있다.

```text
male
female
```

문자열 데이터는 사람이 이해하기에는 쉽지만, 머신러닝 알고리즘에서는 숫자로 변환하여 사용하는 경우가 많다.

따라서 다음과 같이 숫자로 변환할 수 있다.

```text
male   → 0
female → 1
```

---

# 5. map()을 이용한 성별 인코딩

Pandas의 `map()`을 이용하면 특정 값을 원하는 값으로 쉽게 변환할 수 있다.

```python
df["Sex"] = df["Sex"].map({
    "male": 0,
    "female": 1
})
```

변환 결과는 다음과 같다.

```text
변환 전

male
female
female
male
```

```text
변환 후

0
1
1
0
```

---

# 6. 기존 컬럼을 유지하면서 새로운 컬럼 만들기

원본 `Sex` 컬럼을 그대로 유지하고 싶다면 새로운 컬럼을 만드는 방법이 더 안전하다.

```python
df["Sex_encoded"] = df["Sex"].map({
    "male": 0,
    "female": 1
})
```

이렇게 하면 데이터는 다음과 같은 구조가 된다.

| Sex    | Sex_encoded |
| ------ | ----------: |
| male   |           0 |
| female |           1 |
| female |           1 |
| male   |           0 |

원본 데이터를 보존하면서 변환 결과를 비교할 수 있다는 장점이 있다.

---

# 7. replace()를 이용한 방법

`replace()`를 사용해서도 값을 변경할 수 있다.

```python
df["Sex_encoded"] = df["Sex"].replace({
    "male": 0,
    "female": 1
})
```

`map()`과 비슷하지만, 특정 값을 다른 값으로 단순 치환할 때 사용할 수 있다.

---

# 8. 인코딩이 필요한 이유

컴퓨터는 `male`, `female`이라는 문자열의 의미를 사람처럼 이해하지 못한다.

따라서 머신러닝 모델이나 일부 통계 분석에서 사용할 수 있도록 문자열 데이터를 숫자로 변환해야 한다.

이러한 과정을 **범주형 데이터 인코딩(Categorical Encoding)**이라고 한다.

예시:

```text
male → 0
female → 1
```

숫자의 크기 자체가 성별의 우열이나 순서를 의미하는 것은 아니다.

단순히 두 범주를 컴퓨터가 처리할 수 있도록 숫자로 표현한 것이다.

# 10. unique()로 데이터 값 확인

컬럼에 어떤 값들이 존재하는지 확인할 때는 `unique()`를 사용할 수 있다.

```python
df["Sex"].unique()
```

예상 결과:

```python
array(["male", "female"], dtype=object)
```

데이터를 변환하기 전에 실제 값이 어떤 형태로 저장되어 있는지 확인할 때 유용하다.

---

# 11. value_counts()로 빈도 확인

각 값이 몇 개씩 존재하는지 확인하려면 `value_counts()`를 사용한다.

```python
df["Sex"].value_counts()
```

예시:

```text
male      577
female    314
```

이를 통해 데이터의 분포를 간단하게 확인할 수 있다.

# 13. 오늘 발생한 오류에서 배운 점

Jupyter Notebook에서는 특정 셀을 실행하지 않았거나 변수를 생성하기 전에 사용하는 경우 `NameError`가 발생할 수 있다.

예를 들어 다음 코드에서

```python
df_work["Sex"]
```

`df_work`를 먼저 생성하지 않았다면 오류가 발생한다.

```text
NameError: name 'df_work' is not defined
```

따라서 먼저 데이터프레임을 생성해야 한다.

```python
df_work = df.copy()
```

그 후 사용할 수 있다.

```python
df_work["Sex"]
```

# 14. 원본 데이터 보존

데이터를 전처리할 때 원본 데이터프레임을 직접 수정하는 것보다 복사본을 만들어 작업하는 것이 안전하다.

```python
df_work = df.copy()
```

구조:

```text
df
↓
원본 데이터

df_work
↓
분석 및 전처리용 데이터
```

이렇게 하면 전처리 과정에서 문제가 발생하더라도 원본 데이터를 다시 사용할 수 있다.
